# 浏览器标签页

用 `/browser` 读取你 Chrome 里当前标签页**已渲染**的内容，投递给模型分析。

## 解决什么

`web_fetch` 只能拿到服务器返回的 HTML。后台系统、SPA、弹窗后的表格，在 HTML 里往往什么都没有；图表和 canvas 更是没有文字。这个插件让你浏览器里已经渲染好的页面直接把结果交出来。

## 怎么用

- `/browser` — 读当前页，模型立刻开始分析
- `/browser list` — 看看有哪些标签页可读
- `/browser <关键字>` — 指定另一个标签页

## 需要你做的

1. DSH 里装好本插件（设置页「插件」→ 添加本地目录）。
2. `chrome://extensions` → 开发者模式 → 加载已解压 → 选 `extension/`。
3. 点扩展图标确认地址。

命令只在你说的时候才去读页面，模型不会自己翻浏览器。
